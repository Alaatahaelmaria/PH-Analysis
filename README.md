# PT Analysis

This project contains a static HTML report page for the respiratory and pain threshold study.

## Deploy to Vercel

1. Install Vercel CLI:
   ```bash
   npm install -g vercel
   ```
2. From the project folder:
   ```bash
   cd "c:\Users\Alaat\Downloads\PT Analysis"
   vercel
   ```
3. Follow the prompts. The site will be published to a Vercel URL.

## Use a custom domain

- Add a custom domain in the Vercel dashboard.
- Configure your DNS provider to point the domain to Vercel.
- Vercel will verify the domain and publish the site.

## Notes

- `index.html` is the homepage.
- `vercel.json` configures the static build and route fallback.
